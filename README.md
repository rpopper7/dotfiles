# dotfiles

Personal dotfiles managed with [GNU Stow](https://www.gnu.org/software/stow/).

## Setup (new Mac)

1. **Install [Homebrew](https://brew.sh/)** (this also installs Apple's Command Line Tools, including git).
   Run only the `eval "$(/opt/homebrew/bin/brew shellenv)"` line it suggests; `.zprofile` here handles it
   from then on.
2. **Install [1Password](https://1password.com/downloads/mac/)**, sign in, and turn on
   Settings → Developer → **Use the SSH agent**. Git signing and SSH both depend on it.
3. **Clone over HTTPS** (SSH isn't set up until step 5):
   ```sh
   git clone https://github.com/rpopper7/dotfiles.git ~/dotfiles
   cd ~/dotfiles
   ```
4. **Install the tools:** `brew bundle` (reads `Brewfile`).
5. **Link the dotfiles:**
   ```sh
   stow -n -v .   # dry run: lists conflicts with files that already exist in ~
   ```
   Move any conflicting files aside (e.g. `mv ~/.zprofile ~/.zprofile.bak`; Homebrew's installer
   creates one), then run `stow .` and **open a new terminal**.
6. **Switch the repo to SSH** and sign in to GitHub:
   ```sh
   git remote set-url origin git@github.com:rpopper7/dotfiles.git
   gh auth login
   ```
7. **Node** with nvm (not in Homebrew). `PROFILE=/dev/null` stops the installer from editing `.zshrc`,
   which already loads nvm:
   ```sh
   PROFILE=/dev/null bash -c 'curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash'
   nvm install 24
   ```
8. **beets:** install with uv using the command in the iCloud `All Devices Sync/Music/README.md`.
9. **Apps:** reinstall from their websites or the App Store (they're not in the Brewfile on purpose).

`stow .` creates symlinks from `~` into this repo, so changes are tracked automatically.

### How tracking works
- A dotfile is only tracked if the **real file lives in `~/dotfiles`**. The copy in `~` is a symlink
  pointing here (e.g. `~/.zshrc → dotfiles/.zshrc`).
- Dotfiles that tools create directly in `~` are **not** tracked until you move them in.
- **To add a new dotfile:** move it into `~/dotfiles`, then run `stow .` from here to put a symlink
  back in its place. Check with `ls -la ~/<file>`; it should show `->`.
- `.stow-local-ignore` lists what stow should **not** link into `~`: git files, this README, and
  `.claude/` (Claude Code settings for working in this repo, not for all of `~`).
- `.gitignore` keeps app-generated files and secrets out of git (see beets below).

## Contents

### Neovim (`.config/nvim/`)
Config built on [lazy.nvim](https://github.com/folke/lazy.nvim) with the following plugins:

- **Catppuccin** — colorscheme
- **Lualine** — statusline
- **Telescope** — fuzzy finder
- **Treesitter** — syntax highlighting and indentation
- **Mason** — LSP/linter/formatter installer
- **nvim-cmp** — autocompletion
- **nvim-autopairs** — auto-close brackets
- **nvim-ts-autotag** — auto-close HTML/JSX tags
- **todo-comments** — highlight TODO/FIXME comments

### Zsh
Zsh loads these in order: `.zshenv` → `.zprofile` → `.zshrc`.

- **`.zshenv`** — `EDITOR`/`VISUAL` set to nvim (used by git, `beet edit`, etc.)
- **`.zprofile`** — Homebrew setup (`brew shellenv`) and uv tools on `PATH` (`~/.local/bin`)
- **`.zshrc`**:
  - **Powerlevel10k** — prompt theme
  - **zsh-syntax-highlighting** — command highlighting
  - **zsh-autosuggestions** — inline suggestions
  - **NVM** — Node version manager
  - **1Password SSH agent** (`SSH_AUTH_SOCK`)
  - Git aliases (`gs`, `gb`, `gc`, `gd`, `gl`, `push`, `pull`)
- **`.p10k.zsh`** — Powerlevel10k prompt settings (generated by `p10k configure`)

### Git (`.gitconfig`)
- Name and GitHub no-reply email
- Commits are **signed with an SSH key through 1Password** (`op-ssh-sign`). 1Password must be installed
  and unlocked to commit. The `signingkey` is the *public* key, so it's safe to have in a public repo.
- No credential helper: git uses SSH (1Password agent), not HTTPS passwords.

### Other
- **1Password** (`.config/1Password/`) — SSH agent config
- **gh** (`.config/gh/`) — GitHub CLI preferences and aliases
- **git** (`.config/git/`) — global gitignore
- **beets** (`.config/beets/config.yaml`) — music library manager config. Only `config.yaml` is
  tracked; the library database, backups, and Spotify token are gitignored. The music project itself
  is documented in `README.md` inside the iCloud `All Devices Sync/Music/` folder.

### Homebrew (`Brewfile`)
Command-line tools only; apps are installed manually. Each non-obvious entry has a comment saying
what it's for. Useful commands:

- `brew bundle check` — is everything in the Brewfile installed?
- `brew bundle cleanup` — lists anything installed that the Brewfile doesn't mention (add `--force`
  to uninstall it)
- When you `brew install` something you want to keep, add it to `Brewfile` too.

`python3` is Apple's built-in Python on purpose; use uv (`uv run`, `uvx`, `uv venv --python 3.13`) for
anything newer.
